# Appearance and Settings

Stem's appearance controls live under **Project Settings → Plugins → Stem**. You can change row spacing, base guides and path highlights independently while leaving native Outliner behavior and level content unchanged.

## Topics

| Topic | What you'll learn | Design | Technical |
| --- | --- | --- | --- |
| **Row Height and Spacing** | Adjust the minimum vertical space of World Outliner rows while keeping Unreal's normal labels, icons and selection behavior. | [Design](row-height/DESIGN.md) | [Technical](row-height/TECHNICAL.md) |
| **Guide Visibility, Brightness and Thickness** | Tune how strongly the hierarchy connectors appear without changing the Outliner's actual parent-child structure. | [Design](guide-appearance/DESIGN.md) | [Technical](guide-appearance/TECHNICAL.md) |
| **Highlight Preferences** | Configure selected and hovered path visibility independently while keeping normal connector guides legible. | [Design](highlighting-settings/DESIGN.md) | [Technical](highlighting-settings/TECHNICAL.md) |
| **Project Settings and Persistence** | Stem's settings are project configuration values, not flags saved on individual Actors or folders. | [Design](configuration/DESIGN.md) | [Technical](configuration/TECHNICAL.md) |

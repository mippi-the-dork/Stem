# Integration and Support

Stem is an Editor-only enhancement to Unreal's standard World Outliner. It preserves native label widgets, uses temporary UI state and project settings, and makes no changes to level hierarchy or packaged gameplay.

## What to check first

If guides or highlights don't appear, verify that the plugin is enabled, the correct **standard World Outliner** is open, its branch is expanded and the relevant Stem settings are on. Most troubleshooting begins with those four questions.
